# AI Text Detector (RU)

Веб-детектор ИИ-сгенерированного текста для русского языка. Вставьте текст,
выберите модель (v1–v4) → вероятность того, что текст написан ИИ, + вердикт и
разбивка по признакам.

> ⚠️ Это **вероятностная оценка, а не доказательство авторства**. Любой детектор
> ошибается, особенно на коротких текстах и у неносителей языка. Недопустимо как
> основание для дисциплинарных или академических санкций.

Модель по умолчанию — v4 (порог калиброван под FPR ≤ 3%). Считается на CPU,
локально, без обращений к внешним сервисам.
