# Тестовые тексты

Набор для ручной и регрессионной проверки детектора. Тексты подобраны так, чтобы
покрыть разные случаи: чистый ИИ, чистый человек, смесь в одном документе и
отредактированный ИИ.

## Короткие тексты с разметкой

Шесть файлов плюс `labels.json` (0 — человек, 1 — ИИ):

| Файл | Класс | Что это |
|------|-------|---------|
| `sample_human_1.txt` | человек | разговорный текст, рваные предложения |
| `sample_human_2.txt` | человек | то же, другой стиль |
| `sample_human_3.txt` | человек | то же |
| `sample_ai_1.txt` | ИИ | гладкий текст со штампами («важно отметить», «таким образом») |
| `sample_ai_2.txt` | ИИ | то же |
| `sample_ai_3.txt` | ИИ | то же |

Прогнать всю папку и сверить с разметкой:

```bash
python apps/detect_cli.py --dir samples/
```

Один файл:

```bash
python apps/detect_cli.py samples/sample_ai_1.txt              # модель v4 (боевая)
python apps/detect_cli.py samples/sample_human_1.txt --model v1
```

## Документы (.docx)

Документы для проверки поабзацной карты и сегментации. Правильные ответы — в
`test_key.md` (сканер его не видит, оценивает вслепую).

| Файл | Что проверяет |
|------|----------------|
| `test_diploma.docx` | человеческий диплом — ложных обвинений быть не должно |
| `test_mixed.docx` | смесь человек/ИИ в одном тексте — основной замер recall |
| `test_pure_ai.docx` | сплошной ИИ — должен подняться красным |
| `test_pure_ai_ghost.docx` | ИИ после гуманизатора — труднее ловится |
| `test_ai_edited.docx` | ИИ с ручной правкой |
| `synthetic_doc.txt` | синтетический документ для проверки разбора абзацев |

Карта документа:

```bash
python apps/detector_tui.py --text samples/test_mixed.docx --model v4
```

Регрессия сегментации (отсев титула, оглавления, списка литературы, таблиц):

```bash
python tests/test_segmentation.py
```

## Свои документы

Тексты собственных дипломных работ в репозиторий не выкладываются (они в
`.gitignore`). Если положить `.docx`/`.pdf` в `samples/`, скрипты их подхватят, но
git их не закоммитит. Поддерживаются `.txt`, `.docx`, `.pdf` (см. `aidetector/extract_text.py`).
